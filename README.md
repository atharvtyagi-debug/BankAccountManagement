# Bank Account Management System

## About the Project
This is a simple Java OOP project that demonstrates basic banking operations using classes and objects.

## Features
- Create bank accounts using a parameterized constructor.
- Deposit money into an account.
- Withdraw money with an insufficient balance check.
- Check the current account balance.
- Display account details.
- Maintain independent balances for different accounts.

## Files
- `BankAccount.java` – Contains the BankAccount class and banking methods.
- `Main.java` – Contains the main method and performs operations on two accounts.

## Technologies Used
- Java
- Object-Oriented Programming (OOP)

## How to Run
Compile both Java files:

```bash
javac Main.java BankAccount.java
```

Run the program:

```bash
java Main
```
